Final Year Design Project

KnitTrack

Performance Monitoring and Predictive Analysis for Circular Knitting Machine

IoT · Sensors · Predictive Maintenance

A real-time monitoring system for circular knitting machines.

The project tracks RPM, temperature, pressure, flow, voltage and current. An Arduino-based controller collects the readings, while an ESP8266 sends the data through MQTT to a cloud database.

A Python backend supports dashboard visualisation and a Random Forest model for predictive analysis. Alerts can be sent through the dashboard, buzzer and notification system.

SensorsControllerMQTT + DatabaseDashboard + ML

My contribution: system development, sensor integration, documentation and project presentation as part of a four-member team.
